## Run locally

### Requirements

- Node.js 18+
- npm
- Optional: a Gemini API key for the portfolio assistant

### Setup

```bash
git clone https://github.com/Mr-dhruv-sony/dhruv_sony.git
cd dhruv_sony
npm install
```

Create a `.env` file in the project root if you want to enable the Gemini assistant:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Start the client and server in separate terminals:

```bash
npm run dev
npm run dev:server
```

The client runs on `http://localhost:3000` and the API server runs on `http://localhost:3001`.

## Validate and build

```bash
npm run check
npm run build
npm start
```

The production build creates the client in `dist/public` and bundles the Express server into `dist/index.js`.

## Deployment

Because the portfolio includes an Express API for the AI assistant, deploy it as a Node web service rather than a static-only site.

Recommended settings for Render:

```text
Build command: npm install && npm run build
Start command: npm start
Environment: NODE_ENV=production
```

Add `GEMINI_API_KEY` as a secret environment variable in the deployment dashboard.
